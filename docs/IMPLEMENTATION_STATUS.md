# Implementation status and current issue register

Updated: 2026-09-09. Reviewed source baseline: `15cd1e6`, plus the uncommitted M0 implementation described below. This is the current status companion to the historical [August audit](AUDIT_2026_08_30.md) and the [implementation roadmap](Future%20Implementation%20Roadmap.md).

## Status rules

- **Verified correction:** a targeted regression or browser check supports the stated, bounded behavior.
- **Implemented; verification open:** source contains a change, but its full acceptance scenario is not covered.
- **Needs investigation:** the historical claim needs a current reproduction or independent physical reference.
- **Open:** source inspection confirms the missing behavior or problematic mechanism.
- **Superseded:** the historical description contradicts current source; any broader gap is listed separately.

Severity below is retained from the audit for triage, not proof of a reproduced defect. “Owner” names the subsystem responsible for the next bounded implementation task.

## Preset correction from the reference scenarios

The Les Paul preset had pickup-to-volume-input and volume-wiper-to-selector wiring but no path between each volume input and wiper. All three selector assertions failed with an empty pickup selection. Adding the same explicit volume signal paths used by the Tele/Strat presets fixes connectivity; WDF remains responsible for the loaded taper. This is a bounded M1.1 correction discovered by M0 references, not a claim of complete dual-volume physical modeling.

## Remaining scope

The M0 implementation adds CI configuration, source formatting, safe WASM packaging, a browser audio harness, versioned scenarios, and this register. Local CI-equivalent results are recorded in [VERIFICATION.md](VERIFICATION.md). Hosted CI itself must be observed after push; no remote run or branch-protection configuration is claimed.

The browser harness covers real worklet/WASM startup, passive reference parity, and scheduled pluck/release through the tone stack. It does not certify the complete amp/cab/limiter chain, interactive UI, multi-browser/device support, or physical calibration. Those gates remain M1 onward. Sympathetic coupling, nonlinear pickup response, whammy UI/MIDI, and complete bass implementation remain open.
